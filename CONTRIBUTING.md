# Contributing to Mobile Wallet

Thank you for your interest in contributing!

## Development Guidelines
1. Ensure strict typing and zero warnings.
2. Maintain clean architecture layering: UI depends on Domain, Data depends on Domain.
3. Write unit tests for all domain and security logic.
4. Format code using `.editorconfig` rules.
5. All commits must follow Conventional Commits standard (`feat(scope): ...`, `fix(scope): ...`).
